A `curaye cohere` CLI command that runs the deterministic part of a coherence pass (hardcoded colours, duplicated string templates, inconsistent flag names) and prints findings for `/curaye-cohere` to interpret, the same split as `curaye check` and `/curaye-check`. Out of scope for coherence-pass v1.
